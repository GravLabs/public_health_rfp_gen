# REQUEST FOR PROPOSALS
## Newborn Screening Expanded Panel — Lysosomal Storage Disorders and Genomic Second-Tier Testing
**RFP ID:** Public Health Labs-RFP-2024-NEWBORN2-046  
**Issue Date:** March 4, 2024  
**Federal Sponsor:** Health Resources and Services Administration (HRSA) / MCHB  
**HRSA Award Number:** UA6MC32492-NBS2  
**Program Area:** Newborn Screening — Expanded Panel and Genomics

---

## 1. Background and Purpose

The Recommended Uniform Screening Panel (RUSP) now includes 37 primary and 26 secondary conditions. Recent RUSP additions — including Pompe disease (glycogen storage type II), mucopolysaccharidosis type I (MPS-I), spinal muscular atrophy (SMA), and X-linked adrenoleukodystrophy (X-ALD) — require biochemical and molecular second-tier tests that most state programs implemented rapidly under emergency authorization but without full analytical validation. High false-positive rates for lysosomal storage disorders (LSDs) in first-tier screening using digital microfluidics multiplex enzyme assays have caused unnecessary parental anxiety and costly diagnostic follow-up. Genomic second-tier testing using targeted gene sequencing can dramatically reduce false-positive rates. This RFP funds state NBS laboratories to fully validate expanded RUSP conditions and implement genomic second-tier testing.

## 3. Eligibility Criteria

- Public Health Labs member state NBS laboratory performing RUSP-compliant newborn screening
- CLIA high-complexity certification with CAP NBS accreditation
- Documentation of high false-positive rate (>1% positive predictive value) for ≥1 LSD on current first-tier platform
- State NBS program commitment to implement genomic second-tier testing if validated

---

## 4. Scope of Work

### A. LSD First-Tier Platform Optimization
- Conduct performance evaluation of all LSD enzyme assays currently in use: Pompe, MPS-I, Fabry, Gaucher, Krabbe, Niemann-Pick A/B (if applicable)
- Implement or optimize cutoff adjustments and second-tier biochemical confirmatory testing to achieve PPV ≥5% for all LSD conditions
- Document validation in CLSI EP05-A3 precision and EP09-A3 method comparison formats

### B. SMA Genomic Screening
- Validate and implement SMN1 exon 7 deletion detection by digital PCR or MLPA for SMA newborn screening as RUSP-required second-tier
- Achieve ≥99.9% sensitivity for homozygous SMN1 deletion; specificity ≥99.99%
- Implement reflex to SMN2 copy number for all SMN1 deletion positives to support clinical management decisions

### C. Genomic Second-Tier Testing for LSDs
- Pilot implementation of targeted gene sequencing panel for ≥2 LSD conditions (Pompe and MPS-I minimum) to resolve screen positives with equivocal enzyme activity
- Validate sequencing panel for common pathogenic variants and variant of uncertain significance (VUS) reporting framework
- Achieve 5-business-day turnaround from first-tier screen positive to genomic second-tier result

### D. Reporting and Follow-up Integration
- Implement automated flagging of genomic second-tier results within state NBS tracking and reporting system
- Partner with state NBS follow-up coordinator to track short-term outcomes (confirmed diagnosis vs false positive) for all screen positives in program year 1
- Contribute data to Public Health Labs/HRSA NewSTEPs registry
