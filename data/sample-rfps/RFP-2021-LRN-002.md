**Program Area:** Laboratory Response Network — Biological (LRN-B)

---

## 1. Background and Purpose

The Laboratory Response Network — Biological (LRN-B) is a national network of laboratories capable of responding to biological terrorism and emerging infectious disease threats. Public Health Labs coordinates LRN-B activities for state and local public health laboratories and has received CDC funding to enhance network capabilities post-COVID-19.

This RFP targets LRN-B Reference and Sentinel laboratories for investments in Select Agent testing infrastructure, next-generation sequencing (NGS) capabilities, and bioterrorism threat agent assay validation. The COVID-19 response demonstrated that LRN laboratories with robust NGS capacity responded more rapidly to variant surveillance needs; this funding cycle extends that capability to classical bioterrorism threat agents.

## 3. Eligibility Criteria

- Current public health member laboratory classified as LRN-B Reference or Sentinel level
- Registered with CDC Select Agent Program (for Select Agent work) OR committed to registration within 6 months of award
- BSL-3 containment capability (for Reference level activities) OR BSL-2+ (for Sentinel level)
- Current CLIA certification in high-complexity testing
- Demonstrated participation in LRN proficiency testing with passing scores for prior two test events
- No current CDC corrective action plans outstanding

---

## 4. Priority Areas and Scope of Work

### Priority Area A: NGS Capacity for Threat Agent Characterization
- Validate NGS workflows for at least three Tier 1 biological threat agents (e.g., Bacillus anthracis, Francisella tularensis, Yersinia pestis)
- Develop bioinformatics pipelines for automated threat agent identification with <4 hour time-to-result from sample receipt
- Participate in Public Health Labs/CDC NGS data sharing pilot

### Priority Area B: Select Agent Assay Modernization
- Validate updated CDC-approved real-time PCR assays for assigned threat agents
- Implement automated nucleic acid extraction to reduce hands-on time and contamination risk
- Achieve proficiency on updated Public Health Labs LRN proficiency panel within 90 days of assay implementation

### Priority Area C: Surge Response Packaging and Deployment
- Develop pre-positioned "go kit" reagent packages for field deployment within 4 hours of activation
- Test and document packaging, shipping, and chain-of-custody procedures
- Conduct at least one tabletop exercise simulating a multi-state biological event
